# THEESKAPOOO product film

An English-narrated, full-HD product walkthrough for Tech Titans, using the app's existing logo, palette and workflow. Screens are animated illustrative compositions, not a live screen recording. Student/order data is fictional, and the QR encodes only a demo message, never a payment address.

Deliverables are in `output/`:

- `THEESKAPOOO-Product-Film-English.mp4`: 1920×1080, 30 fps, H.264/AAC with burned-in English captions.
- `THEESKAPOOO-English.srt`: timed English captions.
- `THEESKAPOOO-cover.png`: cover image.
- `THEESKAPOOO-storyboard.png`: nine-scene overview.
- `timeline.json`: scene timings and production disclosure.

Narration uses the locally installed Microsoft Zira English synthetic voice. Music is an original procedural ambient composition generated by `render.cjs`; no downloaded music is used. The demo accurately distinguishes submitted payment references from recipient-confirmed payments, and collection codes from ready notifications.

To edit/rebuild on Windows from the repository root:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File video/launch/narrate.ps1
node video/launch/render.cjs
```

Edit `storyboard.json` for narration, `render.cjs` for graphics and timing. Use `--prepare-only` to create artwork without encoding. `--resume` reuses existing scene MP4s; do not use it after changing scenes or narration. Intermediate audio, images and clips are in `build/`. This workflow does not read credentials, contact the backend, create orders, or make payments.
