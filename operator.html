Printing guide
Verify every payment.

Check the recipient account; references and screenshots are not proof.

Priority orders go first among paid waiting orders. Within each group, the earliest payment goes first. Do not interrupt a print already started.

Prepared PDF applies the ordered pages, copies, copy order, orientation and layout. Use KYOCERA Print for B&W (TASKalfa MZ3200i or 3212i) and Canon PRINT for colour (G3770, shown as G3070 series).

In the receiving app select A4, 1 copy, All pages and 1 page per side. Match orientation, colour and duplex to the card. Do not repeat the ordered copies or layout: they are already inside the PDF. Leave staple/punch off, source/media Auto and use High quality. The printer touchscreen is for photocopying; configure document prints in the phone app.

Prepare phone printing, then Open in print / PDF app shares the prepared file. Prepared PDF download and preview work without file sharing. These actions do not start the printer or prove it printed. Mark printing changes order status only; check the physical output before marking ready.

If preparation refuses a complex or large PDF, download the original and manually apply all order settings. Colour duplex needs a shop check and may require manual sheet turning. Keep only authorised trending masters on the phone; delete ordinary student files after collection.

Mark handed over only after giving the prints to the student: the document files are then deleted. Order and payment records remain.

Notifications work while this app is running; closed-app push is not configured.
